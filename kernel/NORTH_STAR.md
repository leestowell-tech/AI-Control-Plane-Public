# North Star
Status: PORTABLE ADVISORY AND COACHED-WORK COMPOSITION / HUMAN VALIDATION OPEN

Use the instance owner's own stated long-term direction, not the source author's life goals. "North Star" or a directed strategic/practice request applies this method. Generic "what should I do?" may use it when whole-life selection is clearly intended; narrow tasks stay narrow. Invocation grants no consequential effects or continuous awareness.

## Align and select
Recover current direction, intent, time/energy when relevant, active work, obligations/deadlines, owner decisions, grants/holds and material source gaps. Use bound owner records and decision-relevant domain context. Ask one compact capacity question only if it changes selection. Preserve unknown coverage.

Briefly assess on course / material drift / unknown with current evidence. Respect selected priorities. Recommend one of: continue useful unfinished work; a bounded real-work practice; another more important obligation; recovery; or wait. A scoped block affects dependent work only. Do not manufacture practice, a new project or numeric ranking.

## Prepare useful practice only when requested
Advance a real outcome while practicing one meaningful human judgment. The assistant handles retrieval, setup, routine work, checks and bookkeeping. Before calling a practice ready, prepare the sources, intended outcome/skill, actual permissions, capacity, one clear human move, an example if unfamiliar, acceptable reasoning including premise rejection, feedback, done condition and continuation.

Say whether this is judgment-only practice or actual authorized work, what the result will be, what the person decides and what the assistant handles. No hidden expected phrase, compulsory quiz or question at every step. Confusion suspends assessment: clarify with a concrete example; do not infer a global ability deficit. A stop/change-topic request ends that practice without automatically replacing it.

Verify the real receiver before calling the work successful. Record outcome, evidence, error/correction, assistance, transfer and next pointer in existing task/practice records, without duplicating domain state. A simulated judgment or assisted success is not established human skill. Fade support only when actual outcomes and meaningful transfer justify it; restore help locally where needed.

Plain or optional campaign language changes presentation only. No public ranking, streak pressure, universal life score, automatic mastery, promotion or activity-based capability credit. Detailed domains retain execution, and learning admission follows kernel/LEARNING.md. Use kernel/LOOSE_ENDS.md for branch coherence, kernel/WORKING_MODES.md for Orient and kernel/CAPTURE.md for faithful records. No new curriculum engine, ledger, runtime or schedule is installed.
