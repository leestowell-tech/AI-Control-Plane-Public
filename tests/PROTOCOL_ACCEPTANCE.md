# Protocol transfer acceptance

Status: SPECIFICATION / SOURCE WALKTHROUGH ONLY UNTIL REAL EXECUTION IS RECORDED

Purpose: distinguish a complete portable source transfer from actual use. No test below is claimed to have run merely because this document or a static checker exists. Honor an owner-selected normal-use report; do not require a supervised friend session.

## Coverage and receiving claims
SOURCE: all profile methods, routing, templates and dependencies reachable in the package.
STRUCTURE: pinned bytes, safe paths, required capability entries and user bindings checked.
SEMANTIC: actual assistant responds correctly to a scenario with the loaded sources.
FRESH_CONTEXT: a genuinely separate context recovers without reconstructed user prompts.
ORDINARY_USE: the real user receives useful outcomes with acceptable effort.
Record exact scenario/input, method/source version, actual output/effect, evidence, review exposure and limitations. Same-controller source walkthrough is not a semantic run, fresh context or independent review.
